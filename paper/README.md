# Paper

[PDF](submission.pdf) and [LaTeX source](source/main.tex), including the bibliography, style files,
and figures.

Build from the repository root:

```bash
uv run forge paper --rebuild-figures --output results/manuscript
```

Output: `results/manuscript/main.pdf`.

Figure 2 uses the supplied PDF. See [limitations](../README.md#limitations) for unavailable figure sources.
